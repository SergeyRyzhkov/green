# Задача

Ты извлекаешь FAQ из расшифровки строительного видео.

## Строгие правила

- Не придумывай факты, цифры, материалы, нормы или рекомендации, которых нет в исходной расшифровке.
- Ответ формируй только на основании текста расшифровки.
- Сохраняй важные оговорки и условия.
- Не превращай рекламные заявления в проверенные факты.
- Один элемент = один самостоятельный смысловой вопрос.
- `sourceQuestion` — исходная формулировка вопроса, если она есть в расшифровке; если вопрос явно не сформулирован, создай максимально близкую формулировку на основе текста.
- `question` — нормализованный понятный вопрос для пользователя.
- `answer` — содержательный ответ по расшифровке.
- `sections` должны содержать ТОЛЬКО ID из списка ниже.
- `tags` — короткие тематические поисковые метки на русском языке.

# TIPA FAQ — экспериментальная замена

Это набор полных замен для локального TypeScript-проекта, использующего Ollama и `qwen3.5:4b`.

## Файлы

- `src/types.ts` — типы FAQ и ответа модели.
- `src/prompts.ts` — новые промпты извлечения и обогащения.
- `src/validate.ts` — поиск цитат без автоматического расширения до границы предложения, базовая проверка вопроса, дедупликация.
- `src/ai.ts` — вызовы Ollama, повтор запросов, разбор JSON.
- `src/extract.ts` — весь экспериментальный процесс, сохранение FAQ и отчёта отклонённых кандидатов.
- `.env.example` — настройки для копирования в `.env`.

## Установка

Скопируй содержимое `src/` в свой `src/`. Сохрани свои `transcripts/` и `data/sections.json`. Скопируй `.env.example` в `.env` либо перенеси значения в существующий `.env`.

Ожидаются зависимости `dotenv`, `tsx` и TypeScript, уже используемые текущим проектом. Скрипт запуска — существующий `npm run process` или прямой запуск `npx tsx src/extract.ts`.

## Результаты

- `data/faq.json` — найденные пары и AI-обогащение.
- `data/extract-rejected.json` — кандидаты, которые не прошли проверку, с причинами отказа; сюда же попадают ошибки обработки фрагментов.

Перед первым запуском сохрани копию старого `data/faq.json`: новый запуск перезаписывает его.

## Экспериментальные ограничения

Это эвристический локальный прототип, а не строгая семантическая верификация. Нечёткий поиск цитат может давать как ложные отказы, так и ложные совпадения. Проверяй `extract-rejected.json` и несколько десятков записей `faq.json` вручную. Значения порогов можно менять в `.env`.

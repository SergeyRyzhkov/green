# TIPA FAQ — упрощённая версия

Локальный TypeScript-процесс: `transcripts/` → извлечение исходных Q&A → разделы/теги/AI-ответ/сравнение → `data/faq.json`.

## Главные правила

- `question` и `answer` — дословные фрагменты транскрипта, включая ошибки распознавания и стиль автора. Код не записывает сгенерированный текст в эти поля.
- `sections` — массив: один вопрос может относиться к нескольким разделам. Справочник единожды задаётся в `data/sections.json`.
- `tags` — массив строк на русском; общий словарь — `data/tags.json`.
- `relatedIds` — ID похожих FAQ; записи не склеиваются и не теряют собственные ответы.
- `aiAnswer` — отдельный независимый ответ модели.
- `aiComparison` — статус, ориентировочный процент совпадения и краткое объяснение.

## Установка

Требуются Node.js 20+ и Ollama с загруженной моделью. Для Mac с 8 ГБ памяти начните с `qwen3.5:2b`.

```bash
npm install
cp .env.example .env
ollama pull qwen3.5:2b
```

Проверьте, что Ollama запущен. API используется через OpenAI-compatible endpoint `http://localhost:11434/v1/chat/completions`.

Положите расшифровки `.txt` или `.md` в `transcripts/`, затем запустите:

```bash
npm run typecheck
npm run process
```

При первом запуске процесс создаст резервную копию `data/faq.json` перед сохранением, если файл уже существует. Повторно обработанные неизменившиеся транскрипты пропускаются по SHA-256 в `data/processed.json`.

## Команды

- `npm run process` — обработать новые или изменившиеся транскрипты.
- `npm run faq:ai` — заполнить AI-ответы только у FAQ, где `aiAnswer` пуст.
- `npm run faq:reclassify-sections` — заново назначить разделы существующим FAQ, не меняя вопрос, ответ и остальные поля.
- `npm run validate` — проверить ID, разделы и связи.
- `npm run typecheck` — проверить TypeScript.

## Формат FAQ

```json
{
  "version": 1,
  "updatedAt": "2026-10-12T12:00:00.000Z",
  "items": [
    {
      "id": "faq-a1b2c3d4e5f6",
      "question": "Дословный вопрос из транскрипта?",
      "answer": "Дословный ответ автора.",
      "source": "09.txt",
      "sections": ["foundation-soils", "winter-operation"],
      "tags": ["фундамент", "зима"],
      "relatedIds": ["faq-112233445566"],
      "aiAnswer": "Отдельный независимый ответ AI.",
      "aiComparison": {
        "status": "partially_agree",
        "agreementPercent": 75,
        "summary": "Совпадает основной вывод, но различаются условия."
      }
    }
  ]
}
```

## Ограничения

Дословность обеспечивается поиском исходного текста: если модель перефразировала вопрос/ответ и код не может найти его в чанке, пара отклоняется и выводится диагностика. Перекрытие фрагментов помогает не терять пары на границах. Сходство вопросов сейчас определяется локально по пересечению слов; оно помогает найти кандидатов, но не заменяет ручную проверку. Процент согласия — оценка модели, не математически точная метрика.
